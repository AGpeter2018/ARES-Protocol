# ARES Protocol Workspace

This is the root directory for the ARES Protocol development workspace.

## Project Structure

- **[AresProtocol/](./AresProtocol/)**: The core smart contract project (Foundry-based).
  - Source contracts, interfaces, and modules.
  - Comprehensive test suite.
  - Protocol documentation ([README](./AresProtocol/README.md), [ARCHITECTURE](./AresProtocol/ARCHITECTURE.md), [SECURITY](./AresProtocol/SECURITY.md)).

## Quick Start

To build and test the smart contracts, navigate to the `AresProtocol` directory:

```bash
cd AresProtocol
forge build
forge test
```

For more detailed technical information, please refer to the documentation inside the [AresProtocol](./AresProtocol/) folder.
